1. Identificativo Univoco & QR Code di Lotto

URI / GS1 Digital Link generato per ogni lotto produttivo (SKU + LOT).

PIM + PLM LOT

2. Composizione Materiali & Componenti

Tomaia, fodera, suola, metalleria o % fibre ISO ereditate dalla BOM.

PLM BOM L1-L2

Paese/Regione di concia/tessitura, giunteria e montaggio (con filtro privacy B2B).

PLM NETWORK

Assenza Cromo VI, Azo-free, Nikel-free con test report allegati al lotto.

PLM CERT LOT

PLM SUPPLIER
