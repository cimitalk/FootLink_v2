- **[`PRD-006` — Work Orders Hub (Commesse di Fabbrica), Passaporto Pellami & Tracciabilità Conceria LWG/ICEC, e UX Editing Anagrafiche](PRD-006-work-orders-hub-and-leather-traceability-passport.md)** (`FTL-PROD-006`): Specifica funzionale per il lancio commesse di fabbrica da Articolo PLM con vincolo di Stagione/Collezione, matrice di calzata/taglie (Size Breakdown Grid) con fabbisogni BOM, avanzamento a fasi Kanban/Gantt con assegnazione terzisti a 0 €, estensione distinta base per pellami e tracciabilità conceria, e UX avanzata per la modifica sicura delle anagrafiche master.
