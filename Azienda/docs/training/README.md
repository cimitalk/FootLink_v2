## 🎯 Missione del Polo Formativo Footlink

Il polo di formazione Footlink ha l'obiettivo di abbattere a zero le barriere all'adozione del software nei distretti moda e manifatturieri (Fermo-Macerata, Riviera del Brenta, Montebelluna, Santa Croce, San Mauro Pascoli, Napoli).  
Attraverso la metodologia **"Zero-Training UX"**, l'onboarding per ciascun ruolo aziendale è progettato per produrre il primo risultato concreto (BOM completata, bridge configurato, passaporto emesso) in **meno di 15 minuti**.

## 💻 Portali Interattivi Web (Accesso Diretto)

Footlink mette a disposizione due portali web interattivi completi, fruibili direttamente nel browser o dall'interno dell'applicativo:

1. **🎓 Footlink Training Academy (`Applicativo/frontend/public/training_portal.html`):**
   - 6 Percorsi formativi per ruolo (Modelleria, Color Studio, Commerciale PIM, Terzisti L6, Sostenibilità DPP, Executive).
   - **Sandbox Hands-On Interattivo:** Simulatore BOM 3 livelli, simulatore Ponte 1:N, generatore live DPP.
   - **Esame Ufficiale di Certificazione:** 10 domande pratiche con valutazione live e rilascio attestato *Footlink Certified Specialist*.
   - **Glossario Calzaturiero & Tecnico Integrato** con ricerca in tempo reale.
   - **Checklist Operativa "Go-Live in 15 Minuti"** con persistenza stato.

2. **📖 Technical Documentation Portal (`Applicativo/frontend/public/tech_docs.html`):**
   - Architettura 3 Pilastri (ADR-005) e stack tecnologico (FastAPI + React 18 + PostgreSQL).
   - Modello Dati Relazionale Calzaturiero (1:N Bridge, BOM 3 Livelli, Tannery Vault).
   - Sicurezza e Segregazione Multi-Tenant L6.
   - REST API Reference completa con switcher di linguaggio (cURL, Python, TypeScript).
   - Pattern di integrazione ERP (SAP, Stealth) ed E-Commerce (Shopify).
   - Conformità ESPR UE 2024/1781 & GS1 Digital Link.
