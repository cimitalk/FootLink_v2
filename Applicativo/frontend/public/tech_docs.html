Architettura di Riferimento

La Struttura a 3 Pilastri di Footlink

Footlink è progettata conformemente ad ADR-005 secondo una separazione rigorosa in 3 pilastri di root. Questa modularità garantisce che la governance aziendale, il codice applicativo e il portale di controllo del Founder siano totalmente disaccoppiati e versionati in modo indipendente.

REPOSITORY HIGH-LEVEL ARCHITECTURE ADR-005 COMPLIANT
🏢 1. Azienda/

Manifesto di Fondazione, Specifiche Ruoli C-Suite, Registri ADR e Task Object JSON.

💻 2. Applicativo/

FastAPI Backend, SPA React 18, PostgreSQL DDL e Motore di Calcolo BOM.

🎛️ 3. Portale Control/

Dashboard di comando locale del Founder, triage approvazioni L1-L6 e controllo spesa.

Sicurezza & Segregazione Multi-Tenant L6

Nei distretti calzaturieri, i brand concorrenti condividono spesso gli stessi laboratori terzisti (es. giunterie o trancerie). Il protocollo L6 Segregation Guard impedisce fughe di dati sulle distinte base e sui costi:

Cosa è Rigidamente Nascosto ai Terzisti:

  • Prezzo retail e margini commerciali dell'articolo PIM
  • Costi orari e tariffe degli altri laboratori della filiera
  • Dati anagrafici e quantità assegnate ad altri terzisti
  • Codici sorgente e ricette chimiche riservate dei pellami

Cosa Vede il Terzista (Solo la sua fase):

  • Numero di paia assegnate e data di consegna richiesta
  • Scheda tecnica dei soli componenti della sua lavorazione
  • Tasti rapidi "Avvia Lavorazione" e "Completato"
  • Pulsante rapido per scattare e inviare foto difetti pelli

La Distinta Base Calzaturiera a 3 Livelli

I componenti sono categorizzati gerarchicamente nei 3 livelli fisici di assemblaggio. Il motore di costing ricalcola i consumi netti moltiplicandoli per il coefficiente di sfrido di tranciatura $(1 + \text{scrap}/100)$.

Livello Nome Calzaturiero Componenti Tipici Unità di Misura Range Scarto Medio
Level 1 Tomaia (Upper) Vitello, camoscio, puntale, contrafforte, cerniere dm² / paia 16% – 22%
Level 2 Fodera & Accessori (Lining) Fodera vitello naturale, microfibra, stringhe, imbottitura dm² / metri / paia 10% – 14%
Level 3 Fondo & Suola (Sole) Sottopiede montaggio, cambrione acciaio, cassetta gomma, tacco paia / set 0% – 3%
REST API Specifications

Autenticazione e Headers di Contesto

Tutte le chiamate API devono includere gli header di identificazione del tenant e del ruolo per consentire la segregazione e l'audit trail L0-L6.

Header Tipo Obbligatorio Descrizione
X-Tenant-Id String (UUID) Sì Identificativo dell'azienda / brand proprietario dei dati.
X-User-Role Enum Sì admin, product_dev, commercial, subcontractor
X-Vendor-Id String Se Terzista Se valorizzato, attiva la segregazione automatica dei dati L6.
GET /api/bom/tree/{variant_id}
Recupera distinta base completa

Restituisce l'albero della distinta base a 3 livelli, con costing aggregato e semaforo di conformità LWG.

curl -X GET "https://api.footlink.it/api/bom/tree/PLM-SNK-042-IT" \
  -H "X-Tenant-Id: ten_marche_01" \
  -H "X-User-Role: product_dev" \
  -H "Accept: application/json"

Enterprise Integrations

Connessione ERP & E-Commerce

Footlink espone webhook asincroni per dialogare con i sistemi contabili e gestionali di fabbrica (SAP, Stealth, AS400) e con le piattaforme commerciali (Shopify, Joor, Farfetch).

Flusso ERP (Stealth / SAP)

Al momento dello sblocco del campionario (`collection_status: approved`), Footlink invia l'evento webhook bom.locked con l'esplosione dei fabbisogni per taglia, consentendo all'ERP di emettere gli ordini di acquisto pellami e suole.

Flusso E-Commerce (Shopify)

I canali digitali ricevono l'articolo PIM commerciale corredato da composizioni tessili certificate UE, foto modellate e il link univoco del passaporto DPP per visualizzare il badge di sostenibilità direttamente nella scheda prodotto.

Deployment & FinOps Playbook

In conformità alle direttive CRO/CTO, Footlink è progettata per un'impronta computazionale minima (Cost-to-Serve < 0.05 € per modello/mese).

Container Docker Linux Alpine: < 180 MB
Consumo RAM Backend (FastAPI): ~85 MB idle
Database Relazionale: PostgreSQL 16+ con indici GIN
Circuit Breaker FinOps: Attivo (Pause on limit)
