Interoperabilità di Sistema

Integrazione ERP Aziendali (SAP, Stealth 3000, AS400)

Linee guida per connettere Footlink ai sistemi informativi gestionali di fabbrica e contabilità industriale.

Nelle manifatture moda calzaturiere, Footlink opera da Single Source of Truth per l'ingegnerizzazione del prodotto (PLM) e la catalogazione commerciale (PIM). I sistemi ERP rimangono i master per la contabilità generale, la gestione magazzino fisica e gli ordini di acquisto fornitori.

DIAGRAMMA DI SCAMBIO DATI BI-DIREZIONALE
FOOTLINK CORE

Modelli, Distinte Base a 3 Livelli, Quote Last, DPP Passport e Portale Terzisti.

Webhook JSON ➔ bom.locked / phase.done ⬅ REST API PO Status / Inventory
ERP AZIENDALE

SAP S/4HANA, Stealth 3000 o AS400 / IBM i per acquisti, contabilità e magazzino.

Dati Trasmessi da Footlink all'ERP:

  • Distinta base congelata (`bom.locked`) con fabbisogni netti e scarti tranciatura
  • Anagrafica modelli, codici varianti industriali e cartelle colori approvate
  • Avanzamento delle fasi di lavorazione inviate dai terzisti a costo zero
  • Metadati di conformità pelli LWG per la certificazione Dogane / EUDR

Dati Ricevuti dall'ERP in Footlink:

  • Stato di emissione degli ordini di acquisto materie prime (PO Number)
  • Giacenza fisica lotti pelli ricevuti in magazzino centrale
  • Costi consuntivi reali di manodopera per la taratura del costing BOM

Eventi Webhook Outbound

Notifiche HTTP POST asincrone con firma HMAC-SHA256 inviate verso i middleware aziendali.

Evento Trigger di Business Destinatario Tipico
collection.approved La collezione passa da 'Bozza' ad 'Approvata'. ERP (Creazione articoli modello)
bom.locked Distinta base validata per la produzione in serie. ERP Acquisti (Generazione Ordini Materie)
subcontractor.phase_completed Il terzista completa la fase (es. Giunteria 400 paia). WMS & Logistica (Prelievo e Spedizione)
dpp.passport_published Generato e firmato il passaporto conformità ESPR. Shopify / E-Commerce (Metafields QR)

Shopify GraphQL Integration Pattern

Footlink invia l'articolo PIM tramite la mutation GraphQL productCreate o productUpdate, popolando i metafields dedicati alla sostenibilità per mostrare il badge di ecodesign e il QR code scansionabile direttamente nella pagina prodotto: 

mutation CreateProductWithDPP($input: ProductInput!) {
  productCreate(input: $input) {
    product {
      id
      title
      metafields(first: 3) {
        edges {
          node {
            key
            value
          }
        }
      }
    }
  }
}

Sicurezza e Segregazione Multi-Tenant L6

Il protocollo L6 Segregation Guard intercetta ogni query SQL a livello middleware. Se l'utente è autenticato con il ruolo di laboratorio terzista (subcontractor):

Regole di Mascheramento Dati L6:
  • I campi cost_per_pair e total_materials_cost vengono mascherati con null.
  • Le righe di tabella relative ad altre lavorazioni (es. montaggio) sono escluse dalla query.
  • Qualsiasi tentativo di bypass ID genera un evento di sicurezza registrato nell'audit log con codice HTTP 403 Forbidden.

DevOps, Containerizzazione & FinOps Playbook

Specifiche Container Docker

Base: Linux Alpine 3.19 + Python 3.11-slim. Dimensione immagine: < 180 MB. RAM Idle: ~85 MB. Startup time: < 400 ms.

Metrica FinOps Cost-to-Serve

Costo computazionale medio per modello attivo < 0,05 €/mese. Margine lordo SaaS costantemente mantenuto > 75%.
