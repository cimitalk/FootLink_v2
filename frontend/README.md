# Footlink Frontend (`React + TypeScript + Vite + Tailwind CSS`)

Frontend web application for **Footlink**, designed for **0 €/month Free-Tier static/edge hosting** (Cloudflare Pages / Vercel Free) in compliance with [`ADR-002`](../adr/ADR-002-core-architecture-free-tier.md).

## Key Views & Portals
1. **SME & Brand Workspace (Desktop-first):**
   - Unified **1 Commercial Item (PIM) ↔ N Production Variants (PLM)** navigator.
   - Multi-level Bill of Materials (BOM) editor and cost/consumption matrix.
   - Live **EU Digital Product Passport (DPP)** preview and QR code generator.
2. **Zero-Training Subcontractor Portal ("Terzisti a 0 €", Mobile-first):**
   - Magic-link access with zero licensing fees (`0 € forever`).
   - 3-click workflow (`< 5 minutes`) for Italian fashion district workshops (cutting, stitching, lasting, tanning) to confirm production phases and input traceable material lot codes.
